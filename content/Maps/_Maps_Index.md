# 🖼️ Maps — Index

**Status:** #draft / #reviewed

> _Each map is its own note, not just a dropped-in image file. Put the image in this folder, create a note here from [[_Templates/Template_Map]], embed the image with_ `![[Map_Image.png]]`_, and link every political division, geographic feature, settlement, or location the map depicts in its Depicts section. Once linked, the map shows up automatically on each of those pages' own "## Maps" section — nothing to update by hand anywhere else._
>
> _A single division can have several maps at different scales — e.g. the world map showing it as one continent among many, plus its own zoomed-in regional map with local boundaries, landmarks, and settlements. Just link all of them from each map's own Depicts section, and every one will list itself on the division's page automatically._
