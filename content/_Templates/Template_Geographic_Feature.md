**Status:** #draft / #reviewed

_(Placement convention, confirmed by Shane 2026-09-07: continents, oceans, and seas — anything that contains other geographic features — get their own subfolder under `Geography/` (e.g. `Geography/Alduria/`), and this overview page is saved as the folder's own name (`Geography/Alduria/Alduria.md`). Everything nested inside that top-level feature — mountain ranges, rivers, lakes, forests, and so on — is saved as its own file inside that same subfolder, not in a further subfolder, UNLESS it in turn contains its own sub-features (e.g. a specific mountain pass within a mountain range, or the Isle of Vraediris's named zones within it) — in which case that mid-level feature gets its own subfolder the same way, one level deeper. A feature with nothing nested inside it (most rivers, lakes, individual mountain ranges) just gets a single file directly in its parent's folder — no folder of its own, and no Sub-Features section below. Delete the Sub-Features section entirely for a leaf feature like that.)_
